### StaffOps Mentoring · [Portal](https://mentoria.staffops.space)

A mentoring program for people moving into DevOps, SRE and Platform Engineering, built on hands-on labs that are *verifiable*: each lab sets up a broken scenario, you fix it, and a script checks your work item by item, the way production would.

#### Tracks

- 🐧 **Linux** (147 labs, LFCS/RHCSA/RHCE-level): fundamentals, services, storage and LVM, boot and recovery, networking, SELinux and firewall, shell scripting, containers, and automation with Ansible
- 🐳 **Docker** (8 labs + 2 challenges): run and debug containers, volumes and Compose with a database, Dockerfiles and layer cache, slim non-root images, secrets kept out of the image, publishing by digest
- ⚙️ **CI/CD** (in progress): GitHub Actions on real GitHub: your first pipeline, building and publishing images to GHCR, deciding the steps, security gates (Trivy, Semgrep), secrets and permissions
- ☸️ **Kubernetes** (in progress, CKAD/CKA-aligned, on kind): workloads, configuration and health, scheduling, networking, storage, access and security, Helm, troubleshooting

#### 🚧 In development

- **GitOps** with Argo CD
- **DevSecOps basics**: pipeline security, SBOM and supply chain management, internal policies
- **Observability basics**: the LGTM stack, OpenTelemetry, observability vs. monitoring
- **Kubernetes Advanced**: service mesh, deployment strategies, security
- **Platform Engineering**: concepts, developer experience, Internal Developer Platforms (Backstage)

Part of [StaffOps](https://github.com/StaffOps).
