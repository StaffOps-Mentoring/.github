### StaffOps Mentoring

A mentoring program for people moving into DevOps, SRE and Platform Engineering, built on hands-on labs that are *verifiable*: each lab sets up a broken scenario, you fix it, and a script checks your work item by item, the way production would.

Tracks: **Linux** (LFCS/RHCSA-level, 147 labs) → **Docker** → **CI/CD** with GitHub Actions → **Kubernetes**

🚧 **In development:**
- **GitOps** with Argo CD
- **DevSecOps basics**: pipeline security, SBOM and supply chain management, internal policies
- **Observability basics**
- **Kubernetes Advanced**: service mesh, deployment strategies, security
- **Platform Engineering**: concepts, developer experience, Internal Developer Platforms (Backstage)

- **[mentoria-apps](https://github.com/StaffOps-Mentoring/mentoria-apps)**: the lab apps (vitrine, api, cofre, sonda) and their images

Part of [StaffOps](https://github.com/StaffOps).
